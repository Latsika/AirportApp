- Sales List: Items now shows item codes only, without descriptions.
- Sales List: Item Count is hidden from the visible table while backend data/calculations remain unchanged.

- Manage Airlines: added Sales List text color setting for each airline with color picker and preview.
- Sales List: airline names are bold and use the configured airline text color when enabled.
- Database migration: airlines.display_color added as a nullable setting; existing airlines keep default styling until a custom color is enabled and saved.
- Documentation updated for Sales List visual behavior, Light/Dark mode, airline color setup, update/install guidance, and troubleshooting.
