AirportApp release - 2026-07-17 external backups

Release ID:
20260717T102037Z-3683723

Included files:
- AirportApp.exe
- install_update.exe
- RELEASE_INFO.md
- app_release.json

What changed:
- Added Admin -> Account settings -> External backups.
- Admin can save a permanent backup folder outside the AirportApp folder.
- App creates ZIP backups with all runtime .db files, release metadata, and backup_manifest.json.
- Automatic backups write daily, weekly, and monthly ZIPs.
- Manual backup is available through Create backup now.
- Backup settings are stored in backup_settings.json next to AirportApp.exe after Admin saves a folder.

Customer update instructions:
1. Back up the customer's current AirportApp folder before updating.
2. Run install_update.exe.
3. Select the folder that contains AirportApp.exe.
4. Start AirportApp.exe.
5. Log in as Admin and open Account settings -> External backups.
6. Set a backup folder outside the AirportApp folder and save.

The updater preserves airport_app.db and replaces AirportApp.exe plus release metadata.
